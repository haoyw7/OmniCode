# OmniCode Changelog

All notable changes to OmniCode are documented here. Version 0.1.0 starts the
OmniCode release history; earlier upstream releases remain in Git history.

## [Unreleased]

## [0.1.0] - 2026-10-18

<!-- release-notes:en -->

### Initial release

- Establish OmniCode as a personal fork with unified application names, identifiers, data directories, and version 0.1.0 across desktop, Host, and mobile packages.
- Include agent conversations, project workspaces, terminals, change reviews, workflows, and mobile access through Host.
- Keep workflow result messages collapsed by default. Open workflow artifacts in reusable tabs and show workflow and agent icons on their corresponding tabs.
- Use new OmniCode storage locations and keys. Previous application data is not migrated automatically.

<!-- /release-notes -->

<!-- release-notes:zh-CN -->

### 初始版本

- 建立 OmniCode 个人分支，统一应用名称、标识、数据目录，桌面端、Host 和移动端的软件包版本均从 0.1.0 开始。
- 包含智能体对话、项目工作区、终端、改动审查、工作流，以及通过 Host 连接的移动端功能。
- 工作流结果消息默认折叠；产物在可复用的标签页中打开，工作流与子智能体标签显示对应图标。
- 使用新的 OmniCode 数据存储位置和键名，不自动迁移原应用数据。

<!-- /release-notes -->
