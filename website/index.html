01 / WORKSPACE

一个项目，
一个完整的工作现场。

会话、文件、终端、Git 分支与 worktree，在同一个工作区各就各位。自由分屏，让需要的内容并排呈现。

了解项目
02 / ASSISTANT

写代码之外，也照顾日常。

委派任务、关注会话、管理提醒和编辑记忆。让个人助理与你的项目一起，融入每天的工作。

笔记提醒记忆收件箱
03 / CONNECTED

离开桌面，工作仍在身边。

通过共享 Host，在桌面与移动端访问项目会话。换一块屏幕，也能接上之前的思路。

连接设备

从源码运行

先安装并登录一个支持的智能体 CLI。源码开发需要 Node.js 24+、稳定版 Rust 与对应平台的 Tauri 原生依赖。

cd ohmymonocode
npm ci
npm run tauri dev
