从源码运行

需要 Node.js 24+、稳定版 Rust、对应平台的 Tauri 依赖，以及至少一个已登录的智能体 CLI。

终端 
git clone https://github.com/haoyw7/OmniCode.git
cd OmniCode
npm ci
npm run tauri dev
